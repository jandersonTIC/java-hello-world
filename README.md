# Projeto de demonstração

Este projeto escrito em Java 11 com Spring Boot 2.7.18, utiliza a lib twitter4j para acessar o Twitter API e a lib sdk-interno-2.0.0.jar para acessar a API interna.

## Requisitos

- Java 11
- Gradle
- Spring Boot 2.7.18
- Twitter API
- API Interna

## Como executar o projeto

1. Clonar o repositório
2. Executar o comando `./gradlew clean build`
3. Executar o comando `./gradlew run`
